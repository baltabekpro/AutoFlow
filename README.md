# AutoFlow - Auto Service Management System

Backend API для системы управления автосервисом, разработанный на Python (FastAPI) и SQLite.

## 🚀 Возможности

- **Управление клиентами и автомобилями**: Учет клиентов и их транспортных средств
- **Управление заказами**: Создание и отслеживание заказов на обслуживание
- **Управление складом**: Учет запчастей и расходных материалов
- **Автоматические расчеты**: Автоматический пересчет стоимости заказов
- **Управление запасами**: Автоматическое списание со склада при закрытии заказа
- **Аутентификация**: JWT-токены для безопасного доступа
- **Роли пользователей**: Администратор и механик

## 📋 Требования

- Python 3.10 или выше
- pip (менеджер пакетов Python)

## 🛠 Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/baltabekpro/AutoFlow.git
cd AutoFlow
```

2. Создайте виртуальное окружение:
```bash
python -m venv venv
```

3. Активируйте виртуальное окружение:
- Windows:
  ```bash
  venv\Scripts\activate
  ```
- Linux/MacOS:
  ```bash
  source venv/bin/activate
  ```

4. Установите зависимости:
```bash
pip install -r requirements.txt
```

5. Скопируйте файл `.env.example` в `.env`:
```bash
cp .env.example .env
```

6. Инициализируйте базу данных:
```bash
python init_db.py
```

Это создаст базу данных SQLite (`storage.db`) с тестовыми данными и административным пользователем.

## 🚀 Запуск

Запустите сервер разработки:
```bash
uvicorn app.main:app --reload
```

Сервер будет доступен по адресу: `http://localhost:8000`

## 📚 Документация API

После запуска сервера документация доступна по адресам:
- Swagger UI: `http://localhost:8000/docs`
- ReDoc: `http://localhost:8000/redoc`

## 🔌 API Endpoints

### Аутентификация
- `POST /auth/login` - Получить JWT токен
- `POST /auth/register` - Зарегистрировать нового пользователя (только админ)

### Клиенты
- `GET /clients/` - Список клиентов (с поиском)
- `POST /clients/` - Создать нового клиента
- `GET /clients/{id}` - Получить клиента по ID
- `PATCH /clients/{id}` - Обновить данные клиента
- `GET /clients/{id}/vehicles` - Получить автомобили клиента

### Автомобили
- `POST /vehicles/` - Зарегистрировать автомобиль
- `GET /vehicles/{id}` - Получить автомобиль по ID

### Заказы
- `GET /orders/` - Список заказов (с фильтрацией по статусу)
- `POST /orders/` - Создать новый заказ
- `GET /orders/{id}` - Получить детальную информацию о заказе
- `PATCH /orders/{id}/status` - Изменить статус заказа
- `POST /orders/{id}/add-item` - Добавить позицию в заказ

### Склад
- `GET /inventory/` - Список товаров на складе (с поиском)
- `POST /inventory/` - Добавить новый товар (только админ)
- `GET /inventory/{id}` - Получить товар по ID
- `PUT /inventory/{id}` - Обновить данные товара

## 💡 Пример использования

1. Получите токен авторизации:
```bash
curl -X POST "http://localhost:8000/auth/login" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "username=admin&password=admin123"
```

2. Используйте полученный токен для доступа к защищенным эндпоинтам:
```bash
curl -X GET "http://localhost:8000/clients/" \
  -H "Authorization: Bearer YOUR_TOKEN_HERE"
```

## 🧪 Бизнес-логика

### Управление заказами
- При добавлении позиций в заказ автоматически пересчитывается общая стоимость
- При закрытии заказа (статус "closed") автоматически списываются товары со склада
- Система проверяет наличие достаточного количества товара перед добавлением в заказ

### Безопасность
- Пароли хешируются с использованием bcrypt
- JWT токены для аутентификации
- Разграничение прав доступа по ролям

## 🔧 Технологический стек

- **Framework**: FastAPI 0.109.0
- **Database**: SQLite
- **ORM**: SQLAlchemy 2.0.25
- **Validation**: Pydantic 2.5.3
- **Authentication**: JWT (python-jose)
- **Password Hashing**: bcrypt (passlib)
- **Migrations**: Alembic 1.13.1
